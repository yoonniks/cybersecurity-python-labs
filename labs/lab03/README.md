# Реєстр ризиків налаштування робочих станцій (ЛР №3)

Лабораторна робота №3: Прикладні бібліотеки Python для побудови веб-застосунків.
Варіант 15.

## Встановлення залежностей

Активуйте віртуальне середовище та встановіть необхідні пакети:

pip install -r requirements.txt

## Початкове заповнення бази даних

Для створення таблиць SQLite та заповнення бази навчальними даними виконай:

python -m labs.lab03.seed

## Запуск Web API

Для запуску сервера Uvicorn виконайте:

python -m uvicorn labs.lab03.main:app --reload --host 127.0.0.1 --port 8000

Інтерактивна документація Swagger UI доступна за адресою:
http://127.0.0.1:8000/docs

## Приклади запитів

Перевірка доступності сервісу:
curl -i http://127.0.0.1:8000/ping

Отримання списку категорій:
curl -i http://127.0.0.1:8000/categories

Отримання записів з фільтрацією:
curl -i "http://127.0.0.1:8000/records?category_id=1&status=new&limit=5&offset=0"

Створення нового запису:
curl -i -X POST "http://127.0.0.1:8000/records" \
  -H "Content-Type: application/json" \
  -d '{"code": "V15-TEST", "title": "Знахідка аудиту", "category_id": 1, "value": 7.5, "status": "new"}'
